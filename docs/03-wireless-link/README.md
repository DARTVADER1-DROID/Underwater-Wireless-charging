# Wireless Link

The wireless link is the coupled TX/RX resonant coil system.

- [Coil geometry, self-inductance, mutual inductance and coupling](coil-design-and-coupling.md)
- [System architecture](../01-system/architecture.md)

The current calculation assumes coaxial circular planar coils and a 30 mm axial separation. Analytical estimates must be compared with measured coils and, later, a finite-conductor electromagnetic model.
