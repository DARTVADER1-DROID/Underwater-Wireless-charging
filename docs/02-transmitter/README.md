# Transmitter

The transmitter contains the timing source, switching logic, MOSFET gate drivers, full H-bridge and TX resonant network.

- [NE555 timing source](ne555-timing.md)
- [Full H-bridge inverter](h-bridge.md)
- [Transmitter diagrams](../diagrams/README.md)

The circuit is not yet a finalized component-level design. Exact timing components, logic ICs, gate drivers, MOSFETs, dead time and protection values must be selected and simulated.
